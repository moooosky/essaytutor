# 使用说明（Windows）

## 第一次使用

1. **安装 Python**（如果已经有就跳过）
   - 下载地址: https://www.python.org/downloads/windows/
   - 安装时**务必勾选** ☑ "Add Python to PATH"

2. **启动**
   - 双击当前目录下的 `启动.bat`
   - 会自动打开一个黑色命令行窗口 + 浏览器
   - 浏览器自动跳到 http://localhost:8000

3. **首次使用要在右上角 ⚙ 设置中填入**：
   - 火山方舟 API Key
   - 视觉模型接入点 ID（OCR 用）
   - 批改模型接入点 ID（DeepSeek）

## 日常使用

- 直接双击 `启动.bat` 即可
- 用完关掉黑色命令行窗口就行（服务停止）

## 常见问题

**Q: 双击 `启动.bat` 提示 "没有检测到 Python"**
A: 没装 Python 或安装时没勾选 "Add Python to PATH"。重装一次，记得勾选那一项。

**Q: 浏览器打开是空白**
A: 检查黑色命令行窗口是否还开着。如果不小心关了，重新双击 `启动.bat`。

**Q: 端口 8000 被占用**
A: 修改 `启动.bat`，把所有 `8000` 改成别的端口（比如 `8088`）。

**Q: 设置 / 历史记录在哪**
A: 全部存在浏览器 localStorage（Edge 的浏览数据中），换浏览器需要重新填配置。
